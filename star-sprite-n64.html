STAR SPRITE on N64

The AI game engine, rebuilt in C for the Nintendo 64. Type a prompt, get a game — and now that game is a real cartridge.

🔨 FIRST ROM BAKING NOW

What is this?

Star Sprite is an AI game engine: you type a prompt, and it generates a playable game. Every Star Sprite game is really just data — a manifest describing the map, enemies, pickups and goal. So instead of porting one game, we ported the engine to C with Libdragon. One engine port means every game Star Sprite makes can become a real N64 ROM.

The first ROM is the proof of concept: the demo level from the web engine, running natively on N64 hardware. Play it in VR, in an emulator, or on a real console with a flash cart.

How to play

🥽 Vapor64 VR

The home turf — play the cartridge inside Michael's own N64 emulator for Quest.

🖥️ Emulator

Mupen64Plus or Ares on PC. Load the .z64 and go.

📼 Real N64

SummerCart64 flash cart — the ROM runs on original hardware.

🌐 Web engine

Not into cartridges? The same engine runs in your browser at the Star Sprite site.

Controls (first ROM)

D-pad / analog stick — move
A — shoot
Start — restart
Reach the gold goal tile to win (+500). Enemies come 3 at a time, just like the web build.

What's in the first ROM — honestly

  • The demo level, top-down, with the same map, enemies and pickups as the web game.
  • Stylized sprites (the full pixel-art blitter is next).
  • No audio yet, no NPC dialogue UI, no saves — those come in Phase 1.
  • The raycaster view is Phase 2. The engine is real; the dressing-up is still coming.
