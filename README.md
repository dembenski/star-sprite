# Star Sprite

**Type or speak a game idea and play it seconds later — an AI game-making engine for the web and Quest.**

- **Live site:** https://dembenski.github.io/star-sprite/

## What it is

Star Sprite turns a plain-language prompt into a playable game. It generates a validated game manifest — levels, enemies, art, and music — and runs it in one of four engines: 2.5D raycast FPS, top-view shooter, side-scroll shooter, or true 3D (WebGL).

- **Providers:** Meta AI (Muse Wonder) first, Groq as backup, and a free offline mode built in.
- **Voice:** speak your idea on Quest — the engine records it and transcribes it with Groq Whisper.
- **Standalone export:** any generated game can be exported as a single self-contained `.html` file that plays offline, even from `file://`.
- **Quest app:** a SideQuest wrapper (Star Sprite Quest) runs the engine as a floating panel in passthrough — see [dembenski/star-sprite-quest](https://github.com/dembenski/star-sprite-quest).

Star Sprite was Michael Dembenski's entry for the Meta AI Developer Hackathon (October 2026) and keeps growing as his own engine. Built by **Michael Dembenski & Bit**.
