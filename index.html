Welcome to Star Sprite — first time here?
Star Sprite is an AI game-making engine: type a prompt, get a playable game.
1. Play the demo — click "Built-in demo map". No key needed.
2. Build a game with no key — Advanced tab, then Offline Game Maker. Pick a theme and build.
3. Edit by hand — Advanced tab, then Hand Editor.
4. With a key — Make game tab: type a prompt, pick an engine, click Generate. Meta Wonder or Groq, your choice.

Blender Gizmo — Bit, powered by the selected provider

Prompt → the selected provider designs a Blender world for the CURRENT level here. Needs a saved key for the selected provider. No key? The Gizmo says so — it does not invent a local plan. In Blender: Scripting → Open → Run Script.

Import From Blender (back into the game)

1. In Blender, run star-sprite-exporter.py. 2. Drag the exported .ss.json OR a .obj file ONTO the game. 3. It spawns 2 tiles in front of the player, auto-selected. 4. In Advanced > Model Studio: recolor it, give it a generated texture, upload a texture, or paint it yourself.

Or just drag & drop the file onto the game screen. .obj = geometry. .png/.jpg dropped after = its texture.

Share link saves WHERE the model sits. Re-drop the same Blender file and it will snap back onto that spot.

Free textures — Poly Haven + Wonder Textures

Free CC0 textures from Poly Haven (public domain, no attribution). Pick a surface, then click a texture to put it on this level. It rides in the level's shared link, feed save, and export, and sticks to newly generated or remixed levels until you clear it. Poly Haven textures need internet — if one fails to load, the level keeps its current look. Wonder Textures are built into the app itself, need no internet, and never get lost — send Bit a Wonder texture to add one here. Painted textures are already built into every level; this card only adds the free photo textures.
