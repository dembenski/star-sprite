Blender Gizmo — Bit, powered by the selected provider

Prompt → the selected provider designs a Blender world for the CURRENT level here. Needs a saved key for the selected provider. No key? The Gizmo says so — it does not invent a local plan. In Blender: Scripting → Open → Run Script.

Import From Blender (back into the game)

1. In Blender, run star-sprite-exporter.py. 2. Drag the exported .ss.json OR a .obj file ONTO the game. 3. It spawns 2 tiles in front of the player, auto-selected. 4. In Advanced > Model Studio: recolor it, give it a generated texture, upload a texture, or paint it yourself.

Or just drag & drop the file onto the game screen. .obj = geometry. .png/.jpg dropped after = its texture.

Share link saves WHERE the model sits. Re-drop the same Blender file and it will snap back onto that spot.
